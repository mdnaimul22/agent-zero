# Right Click

Right-click a sidebar chat or task, or a file/folder entry in list or icon view,
to open its existing action menu at the pointer. Chat menus also include
**Open in Files**, **Save Chat** (for the clicked chat), and **Load Chat**, alongside
Pin and Rename. Open in Files uses the clicked chat's saved folder under
`usr/chats`, regardless of its project, and the existing canvas/window preference
without selecting that chat. Chats without a saved folder yet open `usr/chats`.
The three-dot buttons keep their original menus.

File menus include **Download** and **Delete** (click again to confirm), along
with the existing **Edit** action for Editor and **Open in Browser/Desktop** for
supported file types. Folders offer **Open** and **Download ZIP**. Remote actions
respect the connection's permissions.

Use the arrow keys to navigate, Enter to choose, and Escape to dismiss.
Shift + right-click keeps the browser's native menu. File pickers and text inputs
retain their native right-click behavior.

Enabled by default. Disable **Right Click** in Plugins and reload the page to
restore native right-click menus everywhere.
